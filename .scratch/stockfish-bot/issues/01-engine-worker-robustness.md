# 01: Надёжность движка-бота: ошибки воркера и зависший поиск

**What to build:** Бот-соперник устойчив к сбоям движка. Если worker не загрузился, упал или не вернул `bestmove`, поиск завершается ошибкой, статус «Бот думает…» сбрасывается, и последующие ходы не блокируются. Поздний ответ отменённого поиска не влияет на следующий поиск.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] Ошибка загрузки или исполнения worker приводит к отклонению поиска, а не к бесконечному ожиданию.
- [ ] После таймаута/`stop` поздний `bestmove` не применяется и не подхватывается следующим поиском.
- [ ] Таймер поиска не расходуется на рукопожатие (стартует после `ready` либо бюджет разделён явно).
- [ ] `isThinking` возвращается в `false` при любом сбое.
- [ ] Есть тесты на `onerror`/таймаут/поздний `bestmove`; `npm test`, `npm run lint`, `npm run typecheck` зелёные.
