# 02: Идентичность запроса бота (дубль при повторном включении, мигание статуса)

**What to build:** Хук соперника выдаёт не более одного поиска на позицию с учётом идентичности запроса. Повторное включение бота на той же позиции не создаёт второй поиск, а устаревший ответ не сбрасывает индикатор «Бот думает…», пока актуален текущий поиск.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] Повторное включение (`disable → enable`) на той же позиции не порождает второй поиск (generation-токен или эквивалент).
- [ ] Устаревший ответ не гасит `isThinking`, пока идёт актуальный поиск.
- [ ] Есть тесты на оба сценария; `npm test`, `npm run lint`, `npm run typecheck` зелёные.
