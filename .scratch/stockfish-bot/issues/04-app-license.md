# 04: Лицензия приложения (решение и LICENSE)

**What to build:** Определена и зафиксирована лицензия самого Gambit: файл `LICENSE` в корне репозитория и поле `license` в манифесте приложения. Решение принимает владелец проекта, с учётом вендоренного Stockfish под GPL-3.0 (см. ADR 0003).

**Blocked by:** None (can start immediately).

**Status:** ready-for-human

- [ ] Выбрана лицензия Gambit (или явно решено оставить приложение проприетарным).
- [ ] Добавлен файл `LICENSE` в корне.
- [ ] В манифесте приложения задано поле `license`.
- [ ] Решение зафиксировано (ADR или заметка).
