# Gambit

Настольное приложение для игры в шахматы. Домен — состояние шахматной позиции и переходы между позициями; интерфейс лишь отображает позицию и передаёт намерения игрока.

## Language

**Позиция** (Position):
Полное состояние доски в один момент: расположение фигур, чей ход, права на рокировку и взятие на проходе, счётчики ходов.
_Avoid_: состояние партии, состояние доски, game state

**FEN**:
Стандартная текстовая запись позиции; единственный формат, которым домен обменивается с интерфейсом.
_Avoid_: board string, нотация

**Ход** (Move):
Переход из одной позиции в другую, допустимый правилами шахмат. Допустимость определяют правила, а не интерфейс.
_Avoid_: play, turn, полуход

**Дроп** (Drop):
Жест интерфейса: игрок перетаскивает фигуру с исходного поля на целевое и отпускает. Дроп — это намерение, а не ход; ходом он становится только после проверки правилами.
_Avoid_: move (когда речь о жесте)

**Поле** (Square):
Координата на доске в алгебраической нотации (`e2`, `e4`).
_Avoid_: клетка, cell

**Превращение** (Promotion):
Замена пешки, достигшей последней горизонтали, на другую фигуру. В текущей версии допустимо только превращение в ферзя.
_Avoid_: upgrade

**Доска** (Board):
Визуальный виджет, отображающий позицию и принимающий дропы. Доска не знает правил.
_Avoid_: position (когда речь о виджете)

**Движок** (Engine):
Соперник, который сам вычисляет и делает ходы. Запланирован; сейчас игровой цикл — только за игрока.
_Avoid_: AI, бот, компьютер
