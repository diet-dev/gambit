# Турниры

Непрерывный турнир внутри группы: игроки встречаются по лестнице, после каждого раунда позиции пересчитываются. Раздел «Турниры» состоит из подвкладок «Турниры» и «Настройки», игра — из вкладки «Раунды».

## Настройки

Три правила парования:

- **Слабый играет белыми** — кто из пары получает белые. Влияет на то, кто считается победившим при неявке соперника.
- **Ничья** — кому засчитывается ничья при обмене позициями: «в пользу слабого», «в пользу сильного», «без обмена».
- **Неявка** — чем считается неявка: «поражение неявившемуся» или «без последствий».

Настройку, используемую хотя бы одним турниром, нельзя отредактировать или удалить — сохраните изменённую как новую версию или создайте отдельную.

## Турниры

Турнир = название + группа с игроками + дата начала + набор настроек. Группа без игроков не подойдёт. Созданные турниры можно изменять и удалять.

Иконка графика в строке турнира открывает график позиций (см. ниже).

## Раунды

Вкладка «Раунды»: выберите турнир и нажмите «Создать раунд».

- Укажите дату; настройки подставляются из турнира, при желании меняются.
- Пары первого раунда строятся по алфавиту, дальше — по лестнице предыдущего раунда.
- В первом раунде пары можно править стрелками: ↑ меняет игроков местами, ↓ переносит игрока в соседнюю пару.
- Для каждой пары выберите исход: победа одного, ничья, неявка (техпобеда сопернику), неявка обоих.
- Отдыхающие показываются строкой «Не играет: …».

Пары сверяются с расчётными — сохранить произвольно составленный список нельзя.

Ротация: в нечётных раундах при нечётном составе отдыхает последний лестницы, в чётных — первый (и последний, если состав чётный). Отдыхающий сохраняет свою позицию: после чётного раунда возвращается во главу, после нечётного — в конец.

## Результаты раунда

Клик по раунду в списке открывает таблицу: позиция в лестнице после раунда, ФИО, исход (выиграл, проиграл, ничья, техпобеда, техпоражение, игра не состоялась, отдыхал). Таблица только для чтения; клик по другому раунду переключает её, Esc или крестик закрывают.

## График позиций

Иконка графика у турнира открывает линейный график: по горизонтали — раунды, по вертикали — позиция (первое место сверху), по линии на игрока. Легенда под графиком: клик по фамилии скрывает и возвращает линию. Клик по графику другого турнира перерисовывает его без закрытия; повторный клик по тому же турниру закрывает.

## Лестница

Внутри пары игрок, выигравший партию (или получивший техпобеду), поднимается на ступень выше; ничья обменивает игроков согласно настройке «Ничья». Игрок, удалённый из группы, перестаёт попадать в новые пары. Отдых хранится как неполная пара, поэтому позиции всех игроков восстанавливаются по любому раунду.
