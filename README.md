# Gambit

Учебное настольное шахматное приложение для кружка: интерактивная доска, игра против движка Stockfish, библиотека учебных позиций, группы и игроки, турниры с раундами и удалённая доска на телефоне.

Приложение построено на Electron и может быть скомпилировано под Windows, macOS и Linux (`npm run build:win`, `npm run build:mac`, `npm run build:linux`).

## Разработка и продолжение работы

Приложение адресовано школьным учителям, ведущим шахматные кружки, и рассчитано на использование без программиста. Текущая версия написана ИИ-ассистентом через подписку OpenCode Go (около 10 долларов в месяц) примерно за 5 дней.

Продолжить работу может человек без навыков программирования, тем же способом:

- Установить ИИ-агента (OpenCode) с подпиской, скачать репозиторий и открыть его каталог в агенте.
- Описывать задачи обычным языком — правки в код агент вносит сам.
- Правила работы агента заданы в `AGENTS.md`: язык общения, обязательные уточняющие вопросы, отметка выполненных пунктов, проверки.
- Домен и терминология — в `CONTEXT.md`, принятые решения — в `docs/adr/`, задачи — в `.scratch/<feature>/`.
- Установить Node.js (LTS) и зависимости: `cd app && npm install`. Запустить приложение: `npm run dev`.
- Проверять изменения командами `npm run lint` и `npm run typecheck`, при необходимости — `npm test`.

Роль человека — сформулировать требование и принять результат; писать код вручную не требуется.

Файл `skills-lock.json` фиксирует набор инженерных скиллов (источник — `mattpocock/skills`) и их версии. Он не обязателен: агент работает и без него. Вместо этого набора можно подключить альтернативный, например superpowers.

Для визуальной проверки интерфейса агенту полезен MCP (Model Context Protocol) — протокол подключения внешних инструментов. Рекомендуется сервер playwright: он даёт агенту управление браузером и снимки экрана.

Более подробные инструкции по установке можно получить у самого агента — достаточно попросить его установить и настроить любой из этих компонентов (набор скиллов, MCP-сервер) под вашу систему.

## Стек

- Electron + electron-vite
- React + TypeScript
- `chess.js` (правила), `react-chessboard` (доска), Stockfish (движок-соперник)
- SQLite через встроенный `node:sqlite`
- `ws` (WebSocket для удалённой доски), `chart.js`, `qrcode`
- Vitest + Testing Library

## Структура

- `app/` — единственный пакет, всё приложение
  - `app/src/main` — main-процесс Electron: окно и жизненный цикл, база SQLite и хранилища доменов, IPC-хендлеры, локальный веб-сервер удалённой доски
  - `app/src/preload` — мост в renderer (типизированный `window.api`)
  - `app/src/renderer/src` — React-приложение и игровая логика: `engine/` (Stockfish), `chess/` (правила и представление), `components/`, `hooks/`, `help/`, `remote/`
  - `app/src/shared` — общие типы и контракты IPC между процессами
- `CONTEXT.md` — словарь домена
- `docs/adr/` — архитектурные решения
- `docs/agents/` — настройка инженерных скиллов (трекер, лейблы, доменные доки)

## Проверки

```bash
cd app
npm run lint
npm run typecheck
npm run test:file -- <путь>   # один файл
npm run test:changed          # изменённые тесты
npm test                      # весь прогон, для крупных правок
```

## Возможности

- Интерактивная доска: дропы фигур, подсветка ходов и шаха, превращение пешки в ферзя.
- Соперник-движок Stockfish с выбором силы.
- Библиотека учебных позиций (примеров) в базе: группы примеров, просмотр, сохранение текущей позиции, редактирование, удаление, комментарии.
- Группы и игроки: членство many-to-many, фильтр игроков по группе.
- Турниры: настройки, список турниров, раунды с лестницей и неполными парами, оверлеи результатов и график позиций игроков.
- Удалённая доска на телефоне: QR-код, зеркалирование позиции и приём ходов по WebSocket.
- Журнал событий, экспорт базы данных в файл-снимок, светлая и тёмная темы, встроенная справка.

## Чего пока нет

- Выбор фигуры при превращении — доступен только ферзь.
- Полноценная история партий и их сохранение.
