# Дизайн: бот-соперник (Stockfish, чёрные)

Дата: 2026-09-23

## Контекст

Gambit — настольное приложение для обучения шахматам детей. Сейчас игровой цикл
рассчитан только на игрока: доска принимает ходы ребёнка, движок отсутствует.
В `CONTEXT.md` движок (Engine) помечен как запланированный: «Соперник, который
сам вычисляет и делает ходы».

## Цель

Дать ребёнку полноценного соперника: он играет белыми против движка за чёрных.
Уровень силы фиксирован и низок, чтобы ребёнок мог выигрывать. Бот включается
явно, чтобы не мешать режиму изучения ситуаций.

## Область

Входит:

- вендоринг WASM-сборки Stockfish в репозиторий;
- адаптер движка поверх UCI (Web Worker);
- автоматический ход бота за чёрных, когда он включён и ход чёрных;
- переключатель «Играть с ботом» (по умолчанию выключен);
- индикация «бот думает» в строке статуса.

Не входит (в этой версии):

- выбор цвета игроком (ребёнок всегда белые, бот всегда чёрные);
- регулировка сложности (уровень фиксирован);
- бот в режиме ситуаций (там он не ходит);
- анализ, подсказки, оценка позиции, рейтинг.

## Решения

- **Движок:** Stockfish 19, сборка `stockfish-19-lite-single` (однопоточная,
  ~1.8 МБ wasm; не требует SharedArrayBuffer и COOP/COEP).
- **Источник:** npm-пакет `stockfish@19.0.0` (репозиторий
  `github.com/nmrugg/stockfish.js`; внутри — официальный Stockfish,
  `official-stockfish/Stockfish`). Это сторонняя пересборка, не официальный
  релиз; провенанс фиксируем хэшем и версией.
- **Вендоринг:** файлы кладутся в репозиторий, чтобы сборка приложения не
  зависела от npm-скриптов и сети.
- **Сложность:** фиксированный лёгкий уровень (Skill Level, конкретное значение
  подбирается при реализации по фактическому поведению).
- **Активация:** переключатель «Играть с ботом», по умолчанию выключен.

## Архитектура

Правила остаются у `chess.js` (ADR 0001), игровая логика — в renderer
(ADR 0002). Движок подключается в renderer как ещё один источник намерений:
он отдаёт UCI-ход, который проходит ту же проверку правилами, что и ход
ребёнка.

```
┌─────────────────────────────────────────────────────────────┐
│ renderer                                                     │
│                                                              │
│  ChessGame (UI)                                              │
│    ├─ toggle «Играть с ботом»                               │
│    ├─ status-bar                                            │
│    └─ useChessGame ── позиция/статус ──► useEngineOpponent   │
│             ▲                                  │             │
│             │ playMove({from,to,promotion})    │ findBestMove│
│             └──────────────────────────────────┘             │
│                                                  │           │
│                                         createStockfishEngine│
│                                                  │           │
│                                         uciTransport (Worker)│
└──────────────────────────────────────────────────┼───────────┘
                                                    ▼
                              public/stockfish/stockfish-19-lite-single.js + .wasm
```

### Компоненты

**Ресурсы движка** — `app/src/renderer/public/stockfish/`:

- `stockfish-19-lite-single.js`
- `stockfish-19-lite-single.wasm`
- `README.md` — версия, источник, sha256, лицензия
- `Copying.txt` — текст GPLv3

Каталог `public` выбран потому, что Vite отдаёт его в dev и копирует в сборку,
и рендерер может загрузить воркер по URL. `app/resources/` (extraResources
electron-builder) рендереру по URL недоступен.

**`engine/uciTransport.ts`** — узкий интерфейс транспорта:

```ts
export type UciTransport = {
  post(message: string): void
  onMessage(handler: (line: string) => void): void
  terminate(): void
}
```

**`engine/workerTransport.ts`** — `createWorkerTransport(url)` поверх
`new Worker(url)`.

**`engine/stockfish.ts`** — глубокий модуль движка:

```ts
export type Engine = {
  setSkillLevel(level: number): Promise<void>
  findBestMove(fen: string): Promise<string> // UCI-ход, напр. "e7e5", "e7e8q"
  dispose(): void
}

export function createStockfishEngine(transport: UciTransport): Engine
```

Скрытая реализация: UCI-рукопожатие (`uci` → `uciok`), настройка опций
(`setoption`), постановка позиции (`position fen`), запуск поиска (`go`) и
разбор строки `bestmove`. Наружу — только три метода.

**`useChessGame`** — добавляется публичный `playMove`:

```ts
playMove(args: { from: string; to: string; promotion?: string }): boolean
```

Используется и ходом бота, и (при желании) программными ходами; внутри — тот же
`applyMove`, что у дропа и клика.

**`useEngineOpponent`** — координация бота и игры:

```ts
useEngineOpponent(options: {
  enabled: boolean
  fen: string
  turn: 'w' | 'b'
  isGameOver: boolean
  playMove: (args: { from: string; to: string; promotion?: string }) => boolean
}): { isThinking: boolean }
```

Когда `enabled` и ход чёрных и игра не окончена — запрашивает `findBestMove` и
играет ход. Экземпляр движка создаётся лениво и уничтожается при размонтировании.

**`ChessGame`** — переключатель, подключение `useEngineOpponent`, статус.

### Поток данных

1. Ребёнок делает ход белыми (дроп или клик) → `useChessGame` применяет ход,
   обновляет позицию/статус.
2. Если бот включён и ход чёрных и игра не окончена → `useEngineOpponent`
   вызывает `findBestMove(fen)`.
3. Ответ парсится в `{ from, to, promotion }` и передаётся в `playMove`.
4. `chess.js` проверяет ход правилами; при успехе позиция и статус обновляются.

### Разбор UCI-хода

`e7e5` → `{ from: 'e7', to: 'e5' }`; `e7e8q` → `{ from: 'e7', to: 'e8',
promotion: 'q' }`. Разбор — чистая функция, покрывается юнит-тестами.

## CSP

В `app/src/renderer/index.html` в `script-src` добавить `'wasm-unsafe-eval'`
(компиляция WebAssembly в Chromium), иначе движок не запустится.

## Тестирование

- `uciTransport`/`stockfish` — фейковый транспорт, эмулирующий ответы UCI:
  рукопожатие, установка опций, разбор `bestmove`, превращение.
- разбор UCI-хода — юнит-тесты, включая превращение и некорректные строки.
- `useEngineOpponent` — фейковый движок: ходит, когда включён и ход чёрных; не
  ходит, когда выключен; не ходит после окончания игры.
- `ChessGame` — рендер переключателя; статус «бот думает».
- Ручная проверка в браузере: включить бота, сыграть ход белыми, увидеть ответ.

## Риски

- **Загрузка Worker+wasm под `file://`** в упакованной сборке Electron может
  отличаться от dev. Проверяется в dev; при проблемах — корректировка
  (`locateFile`/абсолютный URL/`asarUnpack`). Отмечается при реализации.
- **Провенанс:** сторонняя пересборка. Митигации: точный пин версии, сверка
  sha256, вендоринг в репозиторий, установка с `--ignore-scripts`.
- **Лицензия:** Stockfish под GPL-3.0. При распространении приложения
  необходимо приложить текст лицензии и атрибуцию движка.

## Открытые вопросы

- Конкретное значение Skill Level для «лёгкого» уровня — подбирается при
  реализации (ориентир: 0–2 плюс ограничение по времени/глубине).
- Нужен ли визуальный индикатор хода бота на доске (подсветка) — вне области,
  при необходимости отдельной задачей.
