# Правила шахмат делегированы `chess.js`

Правила игры целиком отданы библиотеке `chess.js`: она — единственный источник истины о том, какие ходы допустимы. Интерфейс передаёт намерение (дроп), библиотека либо принимает его как ход, либо отклоняет, и только принятый ход меняет позицию. Своей реализации правил в проекте нет.

Так сделано, потому что корректно поддержать рокировку, взятие на проходе, шах, мат и пат дорого и рискованно, а цена ошибки в правилах — сломанная партия. Отвергнутые альтернативы: собственная реализация правил; предварительная проверка хода через список допустимых ходов вместо перехвата отказа библиотеки.

Следствие: нелегальность определяется по отказу `chess.js`; замена библиотеки затронет хук и его тесты.
